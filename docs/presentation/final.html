CHAPTER 07  —  개발 환경 & 빌드·배포
개발 환경 & 빌드·배포
3단계 설치, 클라우드 빌드로 APK 자동 생성
🛠 개발 환경 설정 (3단계)
1
git clone
GitHub에서 소스 복제
2
npm install
의존성 패키지 설치
3
npx expo start
Expo Go QR 코드 스캔 → 즉시 실행
Node.js 20 LTS · Expo Go 앱만 있으면 5분 안에 실행
🚀 빌드 & 배포 (EAS Build)
개발 중
Expo Go
QR 코드 → 실시간 확인 (APK 없이 즉시 테스트)
테스트
eas build --profile preview
클라우드 APK 자동 생성 · 실기기 설치 검증
배포
eas build --profile production
서명된 릴리즈 APK 생성 · Expo 대시보드 다운로드
