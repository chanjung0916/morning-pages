# 기획서 및 요구사항

## 1. 비전

> **"매일 아침 2~3분, 오늘의 나를 내가 정한다."**

바쁜 일상 속에서도 하루를 주도적으로 시작할 수 있도록,
짧고 간결한 아침 일기 습관 형성을 돕는 모바일 앱.

---

## 2. 문제 정의

| 문제 | 현재 상황 | 우리의 해결 |
|---|---|---|
| 종이 일기는 휴대 불편 | 매일 들고 다니기 어려움 | 스마트폰으로 언제 어디서나 |
| 일반 메모앱은 감성 없음 | 그냥 텍스트 입력만 | 주제 프롬프트로 생각 유도 |
| 뭘 써야 할지 모름 | 빈 화면 앞에서 멈춤 | AI 생성 주제로 시작점 제공 |
| 과거 기록 찾기 어려움 | 스크롤해서 찾아야 함 | 달력, 날짜 필터, 잔디 그래프 |
| 인터넷 없으면 못 씀 | 클라우드 앱의 한계 | 100% 오프라인 로컬 저장 |

---

## 3. 사용자 페르소나

**주 사용자: 20대 학생/직장인**

- 아침에 5분도 여유가 없다
- 일기를 쓰고 싶지만 무엇을 써야 할지 모른다
- 오늘 하루를 의미 있게 시작하고 싶다
- 과거 기록을 가끔 돌아보고 싶다

---

## 4. 핵심 기능 요구사항

### Must Have (필수)

| 기능 | 설명 | 구현 |
|---|---|---|
| 일기 작성 | 날짜별 일기 작성 및 저장 | ✅ WriteScreen |
| 일기 조회 | 저장된 일기 목록 및 상세 보기 | ✅ HomeScreen, DiaryDetailScreen |
| 일기 수정/삭제 | 기존 일기 편집 및 삭제 | ✅ DiaryDetailScreen |
| 오프라인 동작 | 인터넷 없이 전체 기능 사용 | ✅ AsyncStorage |
| 오늘의 주제 | 매일 다른 글쓰기 주제 제시 | ✅ CustomTopicRepository |

### Should Have (중요)

| 기능 | 설명 | 구현 |
|---|---|---|
| 즐겨찾기 | 마음에 드는 일기 별표 표시 | ✅ FavoritesScreen |
| 캘린더 뷰 | 날짜 기반 일기 탐색 | ✅ CalendarScreen |
| 기록 그래프 | 잔디형 연간 작성 현황 | ✅ ContributionGraph |
| 날짜 필터 | 연도/월별 필터링 | ✅ RecordsScreen |
| 다크모드 | 눈 편한 야간 모드 | ✅ ThemeContext |
| 알림 | 매일 정해진 시간 일기 알림 | ✅ expo-notifications |

### Could Have (개선)

| 기능 | 설명 | 구현 |
|---|---|---|
| AI 주제 생성 | ChatGPT/Claude에 보낼 프롬프트 생성 | ✅ TopicPromptModal |
| 프로필 | 이름, 생일, 슬로건 설정 | ✅ ProfileScreen |
| 폰트 크기 | 작게/보통/크게 설정 | ✅ ThemeContext |
| 카테고리 필터 | 주제 카테고리별 필터링 | ✅ HomeScreen, FavoritesScreen |

---

## 5. 비기능 요구사항

| 항목 | 요구 사항 |
|---|---|
| 성능 | 앱 시작 3초 이내, 일기 저장 1초 이내 |
| 오프라인 | 인터넷 없이 100% 기능 동작 |
| 데이터 보안 | 모든 데이터 기기 내 저장, 서버 전송 없음 |
| 호환성 | Android 6.0+, iOS 13+ |
| 접근성 | 폰트 크기 조절 (소/중/대) |

---

## 6. 화면 목록

| 화면 | 역할 |
|---|---|
| HomeScreen | 메인: 슬로건, 잔디 그래프, 지난 일기 목록 |
| WriteScreen | 일기 작성: 주제 선택, 본문 입력, 저장 |
| DiaryDetailScreen | 일기 상세: 내용 보기, 수정, 삭제, 즐겨찾기 |
| RecordsScreen | 전체 기록: 날짜 필터, 월별 그룹 |
| FavoritesScreen | 즐겨찾기 목록: 카테고리 필터 |
| CalendarScreen | 달력: 일기 있는 날 점 표시, 날짜 탭 이동 |
| SettingsScreen | 설정: 알림, 테마, 폰트, 주제 관리 |
| ProfileScreen | 프로필: 이름, 생일, 슬로건 |
