## 1. 모바일 앱 배포 옵션

| 옵션 | 난이도 | 학습 효과 |
|---|---|---|
| 로컬 APK 사이드로드 | ★ | 중 |
| Firebase App Distribution / TestFlight | ★★ | 상 |
| Google Play Internal Testing | ★★★ | 상 |
| **Codemagic / EAS Build / GitHub Actions** | ★★★ | 최상 |

### Morning Pages 선택: EAS Build

```bash
# 개발 중 — Expo Go QR 스캔
npx expo start

# 테스트용 APK (클라우드 빌드)
eas build --profile preview --platform android

# 릴리스 APK
eas build --profile production --platform android
```

- 개발 PC에 Android SDK 설치 없이 클라우드에서 APK 자동 생성
- Expo 대시보드에서 다운로드 → 실기기 설치

## 7. Q&A 대비 (4개 핵심 질문)

### Q. 앱 구조는 어떻게 되어 있나요?
`Presentation → Application → Domain → Data` 4계층 구조.  
`src/presentation/screens/` → 화면, `src/domain/usecases/` → 비즈니스 규칙,  
`src/data/repositories/` → AsyncStorage 연동. 단방향 의존으로 각 레이어 분리.

### Q. 개발 환경 설정은?
`git clone` → `npm install` → `npx expo start` 3단계. Node.js 20 LTS만 있으면 5분 안에 실행.

### Q. 빌드와 배포는?
개발 중: Expo Go QR 스캔. 배포: `eas build --platform android --profile preview` 한 명령으로 클라우드 APK 자동 생성. 개발 PC에 Android SDK 불필요.

### Q. ADR이 무엇인가요?
Architecture Decision Record — 왜 이 기술을 선택했는지 추적 가능하게 기록.  
ADR-001: AsyncStorage 선택 이유 / ADR-002: Expo Managed 채택 / ADR-003: Layered Architecture 채택.
