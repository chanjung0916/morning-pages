# 비전 및 목표 — 아침 일기 (Morning Pages)

## 한 줄 요약

매일 아침 자신의 생각과 감정을 자유롭게 기록하고, 과거의 나를 돌아볼 수 있는 모바일 일기 앱

---

## 배경 및 문제 정의

많은 사람들이 아침에 하루를 시작하기 전 생각을 정리하고 싶어하지만,
종이 일기는 휴대가 불편하고 일반 메모앱은 감정 기록에 특화되어 있지 않다.

**핵심 불편함:**
- 언제 어디서든 꺼내 쓸 수 있는 간단한 일기장이 없다
- 오늘의 기분·감정을 빠르게 기록하는 기능이 부족하다
- 과거의 일기를 날짜별로 쉽게 찾아보기 어렵다
- 매일 쓰도록 유도하는 알림 기능이 없다

---

## 비전

> "매일 아침 2~3분, 오늘의 나를 기록한다."

아침 일기 앱은 사용자가 하루를 시작하는 루틴으로 자리잡을 수 있도록
**단순하고 빠른 기록 경험**을 제공한다.
복잡한 기능보다 **매일 쓰고 싶은 앱**을 만드는 것이 목표다.

---

## 목표

| 구분 | 내용 |
|---|---|
| 사용자 목표 | 매일 아침 일기를 쓰는 습관 형성 |
| 제품 목표 | 직관적인 UI로 30초 안에 일기 작성 시작 가능 |
| 기술 목표 | 오프라인에서도 완전히 동작하는 로컬 저장 기반 앱 |

---

## 타겟 사용자

- 일기 쓰는 습관을 만들고 싶은 20~30대
- 감정·기분을 간단하게 기록하고 싶은 사람
- 스마트폰을 주로 사용하는 사람

---

## 플랫폼 선택: React Native (Expo)

| 항목 | 이유 |
|---|---|
| iOS + Android 동시 지원 | 단일 코드베이스로 두 플랫폼 모두 커버 |
| 빠른 개발 속도 | Expo managed workflow로 환경 설정 최소화 |
| JavaScript/TypeScript | 웹 개발 경험 활용 가능, 학습 곡선 낮음 |
| 커뮤니티 | 풍부한 라이브러리 생태계 |

> **대안 검토:** Flutter(성능 우수하나 Dart 학습 필요), 네이티브(플랫폼별 개발 2배 비용)
> → 기말 프로젝트 기간(6주) 내 완성 가능성을 고려해 **Expo** 선택

---

## 성공 기준

- [ ] 날짜별 캘린더 뷰에서 과거 일기 확인 가능
- [ ] 매일 아침 알림 푸시 발송
- [ ] 기분(이모지/점수) 기록 가능
