# 요구사항 — 아침 일기 (Morning Pages)

## 핵심 사용자 시나리오

### 시나리오 1 — 아침 일기 쓰기
> 사용자가 아침에 앱을 열면 오늘 날짜의 빈 일기장이 바로 보인다.
> 선택한 주제에 맞는 아침 제시어("오늘 하루 어떻게 보내고 싶어?" 등)가 상단에 표시되고,
> 기분을 이모지로 선택하고, 자유롭게 글을 적은 뒤 저장한다.

### 시나리오 2 — 과거 일기 돌아보기
> 캘린더 화면에서 날짜를 탭하면 그날 쓴 일기를 바로 읽을 수 있다.
> 일기가 있는 날은 캘린더에 점(dot)으로 표시된다.

### 시나리오 3 — 알림으로 습관 만들기
> 매일 아침 설정한 시간에 "오늘 일기를 써볼까요?" 푸시 알림이 온다.
> 알림을 탭하면 앱이 열리며 바로 작성 화면으로 이동한다.

## MoSCoW 기능 분류

### Must (반드시 있어야 함)

| 기능 | 설명 |
|---|---|
| 일기 작성 | 날짜별 텍스트 일기 작성 |
| 일기 저장 | 로컬 기기에 저장 (오프라인 동작) |
| 일기 조회 | 작성한 일기 목록 및 상세 보기 |
| 일기 수정/삭제 | 작성한 일기 편집 및 삭제 |
| 날짜 자동 기록 | 작성일 자동 저장 |

### Should (있으면 좋음)

| 기능 | 설명 |
|---|---|
| 기분 기록 | 이모지 또는 1~5점 척도로 오늘 기분 선택 |
| 캘린더 뷰 | 월간 캘린더에서 일기 작성 여부 확인 |
| 푸시 알림 | 매일 아침 지정 시간에 일기 작성 알림 |
| 검색 | 키워드로 과거 일기 검색 |
| 주제 선택 & 제시어 | 사용자가 주제를 선택하면 아침 맥락에 맞는 제시어를 작성 화면 상단에 표시. 주제와 제시어는 `src/data/topics.json`으로 관리하며 오프라인 동작. 사용자는 Gemini 프롬프트 템플릿으로 새 주제를 생성해 JSON에 추가할 수 있음. |

**제시어 생성 방식:**

사용자가 원하는 주제어를 아래 Gemini 프롬프트에 넣어 실행 → 결과 JSON을 `src/data/topics.json`에 추가.

```
너는 아침 일기 앱의 제시어 생성기야.

사용자가 입력한 주제: [여기에 주제 입력 — 예: 운동]

조건:
- 아침에 하루를 시작하기 전에 스스로에게 물어볼 수 있는 질문이어야 해
- 오늘 아직 일어나지 않은 일을 전제로 하는 질문 (예: "오늘 어땠어?" 금지)
- 짧고 친근한 말투 (반말 가능)
- 질문 5개 생성

출력 형식 (그대로 복사할 수 있게):
{
  "topic": "[주제]",
  "prompts": [
    "질문1",
    "질문2",
    "질문3",
    "질문4",
    "질문5"
  ]
}
```

**기본 제공 주제 (앱 초기 탑재):**

| 주제 | 제시어 예시 |
|---|---|
| 하루 의도 설정 | "오늘 하루 어떻게 보내고 싶어?", "오늘 꼭 하고 싶은 한 가지는?" |
| 감정 체크인 | "지금 이 순간 기분은?", "요즘 머릿속에 자주 떠오르는 것은?" |
| 자유 글쓰기 | 제시어 없음 — 빈 화면으로 시작 |
| 어제 감사 | "어제 좋았던 일 한 가지는?", "최근 감사한 사람이 있어?" |
| 목표 | "오늘 기대되는 일이 있어?", "이번 주 이루고 싶은 것은?" |

### Could (여유가 있으면)

| 기능 | 설명 |
|---|---|
| 기분 통계 | 주간/월간 기분 변화 차트 |
| 글자 수 표시 | 작성 중 글자 수 실시간 표시 |
| 다크 모드 | 시스템 다크 모드 대응 |
| 태그 | 일기에 태그 추가 및 태그별 필터 |

### Won't (이번 버전에서는 제외)

| 기능 | 제외 이유 |
|---|---|
| 클라우드 동기화 | 로그인/서버 구현 범위 초과 |
| 소셜 공유 | 개인 일기 앱의 방향과 맞지 않음 |
| 사진 첨부 | 저장 용량 및 구현 복잡도 |
| 잠금(비밀번호/생체인증) | 기간 내 구현 우선순위 낮음 |

## 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 성능 | 앱 실행 후 메인 화면 로딩 2초 이내 |
| 오프라인 | 인터넷 없이 전체 기능 동작 |
| 저장 | AsyncStorage 또는 SQLite 로컬 DB 사용 |
| 플랫폼 | iOS 14+, Android 10+ |
